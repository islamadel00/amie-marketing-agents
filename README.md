# a'mie — فريق إيجنتس الماركتنج

مخ الماركتنج لمتجر a'mie (amie-sa.com). لما تفتح الريبو ده في Claude Code، بيتحمّل معاه فريق الإيجنتس والـskills وملف البراند.

## الفريق (`.claude/agents/`)
| الإيجنت | شغلته |
|---|---|
| `amie-seo` | يراجع السيو، وهيكلة الأقسام، واللينكات الداخلية، والـschema، وعناوين جوجل |
| `amie-geo` | يخلّي المحتوى يظهر في إجابات ChatGPT وGemini وGoogle AI، ويكتب الأسئلة والأجوبة |
| `amie-writer` | يكتب أوصاف الأقسام والمنتجات والمقالات والإعلانات بصوت البراند |
| `amie-cro` | يراجع الصفحات ويقترح تحسينات وتجارب تزوّد التحويل ومتوسط الطلب |
| `amie-reviewer` | آخر مراجعة: الحقائق، والادعاءات الممنوعة، والطول، واللينكات، ونبرة البراند |

## البايبلاين
الإيجنت المتخصص يكتب المسودة ← `amie-reviewer` يراجعها ← إنتوا توافقوا ← التنفيذ على زد.
مفيش أي حاجة بتتنشر من غير موافقة.

## ملفات مهمة
- `.claude/product-marketing.md`: كل حاجة عن البراند (المنتجات، الجمهور، الكلمات، الممنوعات). حدّثه لما يتغير أي حاجة.
- `.claude/skills/`: 54 skill من [marketingskills](https://github.com/coreyhaines31/marketingskills) (رخصة MIT).
- `.claude/workflows/amie-seo-geo-categories.js`: بايبلاين أوصاف الأقسام (كتّاب ← مراجعين).

## الاستخدام
1. افتح الريبو في Claude Code (من تبويب Code في Claude Desktop، أو من الترمينال).
2. اكتب طلبك عادي، مثلًا: «خلّي amie-writer يكتب وصف لكل منتجات العناية بالجسم، وamie-reviewer يراجعهم».
3. راجع المسودات، ووافق أو عدّل.
