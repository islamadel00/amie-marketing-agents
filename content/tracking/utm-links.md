# UTM links — a'mie

## Naming rules
- `utm_source`: platform, lowercase — `snapchat`, `tiktok`, `instagram`, `x`
- `utm_medium`: `influencer` (paid or gifted creator posts) · `ugc` · `bio` (own bio link)
- `utm_campaign`: product/campaign + month, e.g. `into-the-glow-2026-10`
- `utm_content`: creator handle/name in Latin, e.g. `ghadi-albarqi`
- Always pair with the creator's Zid coupon code so sales can be matched both ways.
