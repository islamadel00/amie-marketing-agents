# a'mie web identity — proposed direction (2026-10-25)
Board: `reports/amie-web-identity-board.png`. Principles borrowed from the reference audit, expressed in a'mie's own colours and voice (no reuse of moonglaze's exact cream, charcoal, uppercase naming or wordplay).

## Colours (8 only — no red/orange/green)
| Role | HEX |
|---|---|
| Page background (warm rose ivory) | `#F6F0EB` |
| Product-photo background (all products) | `#EADFD7` |
| Primary buttons (approved) | `#663C3C` |
| Headings (a'mie brown) | `#5E2E21` |
| Body text | `#2B2321` |
| Secondary text | `#85756E` |
| Dark sections (chocolate) | `#3A2522` |
| Glow accent (details only) | `#B98B6E` |
Discounts: «وفّري X ر.س» chip in `#663C3C` on `#F1E4E0` instead of red strikethrough-only.

## Type — Readex Pro
- Hero 600 / 30px · section titles 600 / 22px · body 300 / 15px, line-height 1.9 · Latin labels 400 / 11px, letter-spacing 3px.
- Zid theme loads 400/700 only → 300 for body needs custom CSS.

## Components
- Cards: 12px radius, no border/shadow, image on `#EADFD7`, full-width «أضف للسلة» pill.
- Buttons: primary `#663C3C` filled; secondary 1px outline; Apple Pay stays black.
- Spacing: 32px between sections (mobile), 64px (desktop).

## Imagery
- Macro texture/glow shots; Gulf models, warm light; no lifestyle images inside product grids.
- Re-shoot or edit catalogue onto one background (`#EADFD7` family).

## Homepage order (mobile)
1. Thin announcement bar (dark) · 2. Hero macro + short Arabic headline + one CTA · 3. الأكثر مبيعاً (4 cards) · 4. تسوّقي حسب روتينك (6 categories on chocolate) · 5. Texture/season banner · 6. Picks · 7. a'mie & you (reviews/UGC) · 8. Brand story + trust (صنع في السعودية · مسجّلة لدى الهيئة · شحن) · 9. Footer.

## Copy
Short Arabic section titles (1–2 words), calm tone, consistent spelling (اشتري الآن، يبدأ).
